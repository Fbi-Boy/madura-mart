# Master Data Distributor

Modul Distributor menyimpan data distributor Madura Mart.

## Field

- code: kode unik distributor.
- name: nama distributor.
- contact_person: PIC distributor.
- phone: nomor telepon.
- email: email distributor.
- address: alamat.
- city: kota.
- is_active: status distributor.

## Akses

CRUD Distributor hanya tersedia untuk role admin dan super-admin.

Test mencakup akses role, CRUD, dan validasi kode unik.
